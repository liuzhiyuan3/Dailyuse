# Dailyuse 日常使用 · 产品说明

> 面向使用者与运营的说明文档 ｜ 对应版本 v0.1.0

---

## 一、这是什么

**一个装在微信里的日常小工具合集，外加一个「自己说了算」的资讯订阅。**

打开即用，不装 App、不看广告、不刷推荐流。适合两类人：

- 每天要记几件小事、记一笔账、盯几个重要日子的人
- 只想看自己关心的几个关键词，不想被算法投喂的人

## 二、能做什么

### 个人工具

| 工具 | 用来做什么 | 典型用法 |
|------|-----------|---------|
| **待办** | 记下要做的事，勾掉就完 | 开会时想起一件事，两秒记下 |
| **便签** | 临时存一段文字 | 地址、清单、临时想法 |
| **记账** | 收支流水 + 月度汇总 | 午饭花了多少，月底看总数 |
| **倒数日** | 正数/倒数日子 | 生日、考试、还款日 |
| **美食记录** | 今天吃了什么、想吃什么 | 攒一份生活账 |
| **转盘** | 自定义选项，转一下帮你拿主意 | 今天吃什么、谁洗碗 |
| **打卡** | 自己定打卡项，记连续天数 | 喝水、锻炼、背单词 |
| **计时器** | 倒计时（番茄/泡面）+ 秒表计次 | 专注 25 分钟、运动间歇 |

### 协作群组

和家人、朋友共用一个空间。**工具能自己加、自己删**，不只是从列表里挑。

**预设工具**（15 个，点一下就能加）：

| 工具 | 用来做什么 |
|------|-----------|
| 待办 | 交水电费、取快递 |
| 清单 | 买菜、日用品 |
| 记账 | 谁付了多少，自动算均摊和待收/待付 |
| 活动 | 聚会、生日，带日期地点 |
| 计分 | 家务积分、游戏记分，`＋1 / －1` |
| 点餐 | 想吃什么列出来，吃到打勾 |
| 投票 | 单选/多选 + 截止时间，票数实时条形图 |
| 倒数日 | 全群共享的重要日子，还剩多少天一目了然 |
| 接龙 | 报名/集合接龙，按顺序编号，一人一条 | 周六爬山报名、聚会点菜 |
| 公告 | 群内通知，比如「周六下午大扫除」 |
| 菜谱 | 家庭拿手菜，记做法 |
| 链接 | 共享网页、攻略、清单 |
| 快递 | 物品 + 单号，取件不跑空 |
| 值日 | 谁做什么，勾掉就完成 |
| 愿望 | 生日礼物、想买的东西 |

**自定义工具**：输入名字就能建，比如「作业」「宠物喂食」。
自定义工具的内容是勾选清单。

**切换工具**：顶部工具条横向滑动，当前工具是**蓝底白字**；工具多于 4 个时往左滑。

- 点群页右上「⚙ → 编辑工具」：
  - 点工具卡片上的 ✕ 删除
  - 点下方虚线标签添加预设
  - 底部输入名字「新建」自己的工具
- 至少保留一个工具；改名和排序暂不支持
- 群主可移除成员、解散群组；成员可自行退出

## 三、怎么用

### 3.1 第一次使用

1. 打开小程序 → 首页可以直接看（不登录也能浏览）
2. 点任意工具 → 提示「需要登录」→ 点微信登录
3. 登录后数据开始云端保存

> 不登录只能看首页。任何工具、群组、资讯都需要登录后使用。

### 3.2 日常使用

- **记待办**：首页 → 待办 → 底部输入框输入 → 回车
- **勾掉**：点左边的圆圈
- **设提醒**：点条目右侧铃铛 → 选日期时间 → 开启
- **倒数日提醒**：倒数日卡片上的铃铛，默认提醒时间是目标日当天 09:00
- **自定义工具栏**：首页点「编辑」→ 抖动状态 → 加减工具 → 「完成」

### 3.3 和朋友一起用

1. 首页「协作群组」→ 创建群组（或点群头「分享邀请」发到微信群）
2. 对方点开分享卡片会自动加入
3. 群内添加「集体待办」，勾选后进度条实时更新
4. 群主长按成员头像可以移除成员

### 3.4 订阅资讯

1. 资讯页 → 点「＋ 订阅」→ 输入关键词（如「AI」）
2. 微信会弹出授权框 → 点「允许」
3. 服务端定期抓取，有新内容时通过服务通知推给你

**看资讯**：按「今天 / 昨天 / 更早」分组；没读过的标题前有蓝点；下拉可手动刷新。
**管理订阅**：「我的 → 我的订阅」，能看到每个关键词的剩余额度、已抓条数、最后更新时间，可补充额度或删除。

## 四、提醒是怎么工作的（重要）

**微信只允许「一次授权 = 一次推送」。** 所以提醒不是开关，是额度。

当前支持设提醒的对象：**待办**、**倒数日**。

| 项目 | 说明 |
|------|------|
| 授权一次 | 可收到 1 次提醒 |
| 推送一次 | 消耗 1 次额度 |
| 额度用完 | 条目标记「提醒待续」，需要再点一次授权 |
| 改期 | 不消耗新额度，直接改时间即可 |
| 取消 | 点「取消提醒」，不再推送 |
| 免打扰 | 22:00–08:00 不推送，顺延到次日 8 点 |

设提醒时，提醒时间会同时写成该待办的「截止时间」，「今天/本周」筛选据此工作。

## 五、权限：游客能做什么

| 操作 | 游客 | 登录后 |
|------|------|--------|
| 浏览首页、看工具列表 | ✅ | ✅ |
| 进入任一工具 | ❌ 提示登录 | ✅ |
| 创建/查看群组 | ❌ 提示登录 | ✅ |
| 订阅资讯、设置提醒 | ❌ 提示登录 | ✅ |
| 数据跨设备 | ❌ | ✅ |
| 退出登录 | — | ✅（退出后回到游客态） |

登录态有效期 30 天，过期后再次操作会提示重新登录。

## 六、数据与隐私

- **存哪里**：全部存在你自己的服务器数据库里，不经过第三方
- **存什么**：微信 openid（仅用于识别身份）、你输入的内容（待办/便签/账目/群组）
- **不收集**：通讯录、位置、相册、手机号
- **换手机**：登录同一微信账号，数据自动恢复
- **退出登录**：只清除本机登录态，不会删除云端数据

## 七、常见问题

**Q：为什么提示「一次授权只能提醒一次」？**
A：这是微信对小程序的限制，不是产品设计选择。工具类小程序无法申请长期订阅，只能一次一授权。

**Q：资讯为什么收不到推送？**
A：依次检查：① 是否点了「允许」授权；② 额度是否用完（订阅标签上的数字）；③ 是否在 22:00–08:00 免打扰时段；④ 服务端是否配置了推送模板（需管理员配置）。

**Q：群组邀请码在哪？**
A：群组页右上「管理」→ 复制邀请码；或点「分享邀请」直接发微信群。

**Q：群主能退出群吗？**
A：不能。群主需要先解散群组，或把群交给别人（当前版本暂不支持转让，只能解散）。

**Q：能离线用吗？**
A：不能。所有数据在云端，需要联网。

**Q：数据能导出吗？**
A：当前版本暂未提供，后续版本规划中。

## 八、当前版本的能力边界

**已提供**

- 五个工具（待办/便签/记账/倒数日/资讯）的完整增删改查
- 群组：创建、邀请、集体待办、购物清单、AA 记账（自动均摊）、活动、成员管理、解散/退出；「我的群组」列表页
- 待办与倒数日提醒：设置、改期、取消；「提醒」列表页可统一查看和删除
- 资讯：关键词订阅、长按删除订阅、定时抓取、订阅消息推送
- 登录态管理、游客边界、接口限流

**暂未提供**

| 项目 | 说明 |
|------|------|
| 天气 / 番茄钟 / 喝水 | 已从工具栏移除，避免「点开没反应」 |
| 深色模式 | 二期 |
| 数据导出 | 入口保留，功能未实现 |
| 记账分类管理 | 目前是预设分类，不能自定义增删 |
| 月度支出图表 | 目前只有数字汇总 |
| 群组转让 | 群主只能解散，不能移交 |
| 群组待办的提醒入口 | 服务端已支持，界面待开放 |

**已知限制**

- 资讯详情依赖微信「业务域名」白名单，未配置时无法在小程序内打开原文
- 提醒频次受微信一次性订阅限制
- 资讯抓取依赖外部新闻源，需配置 API 后才能拿到真实数据
